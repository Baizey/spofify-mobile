# Settings and appearance

Android always uses the same dark theme, regardless of device appearance, account, or network mode. There is no appearance setting. Previously saved device theme preferences and server-side account colours do not affect the app. Android no longer reads or writes account palettes; this does not change the server API or its stored preferences.

Settings still includes Account and server, Crossfade, Offline mode, Music storage, and About → Credits → Font license. The bundled JetBrains Mono license does not require network access.
