## Portable versus actual integration — preserve the category contract

`app/build.gradle.kts` excludes only `dev.spofify.mobile.testing.RealBrokerIntegration` by default; `true` selects ordinary **plus** integration, malformed boolean fails configuration. Classes/methods using it include RegistrationBrokerContract, PlaybackRegistrationLifecycle, RegistrationHostLifecycle, the real-broker PreparedTransportAppGraph methods, PreparedTransportRemote/ReplacementAppGraph and ExplicitQueueDefaultDeviceAppGraph. Ordinary tests require neither a machine-specific executable nor a sibling checkout. Selected integration requires the explicit immutable pinned Go binary and, for actual website paths, provisioned browser/module/FFmpeg/Python/Node prerequisites; missing prerequisites must fail, never skip or substitute mocks. `.github/workflows/android.yml` already selects full integration and fixture self-tests. Do not change that selection, pins, skips/fallbacks or downloads to make pruning green.

Protocol/real browser/Media3 host simulations have different positive boundaries. A transparent real-response hold/drop proxy and actual broker ACK can validate uncertainty, but only observed Media3 PCM/position or website media time proves those respective pipelines progress. Neither is installed Android proof. Keep native journeys, synthetic fixture checks and mandatory real protocol tests honest and separate.
